# 서바이버 등골 브레이커

Godot 4.3 이상에서 `project.godot`을 열고 F5로 실행합니다. 기본 장면은 `multi_observer.tscn`입니다. 레벨 99 최상급 악마 디아블라가 영웅을 꺾은 역사 장면으로 시작해, 1000년 뒤 후손 다블라가 레벨 1부터 싸우는 10챕터 관찰형 게임입니다.

## 시작과 챕터

- 역사 오프닝: 영화식 연출을 `Enter`로 넘기거나 `Esc`로 건너뛸 수 있습니다.
- 전투 설명서: 첫 실행 후 표시합니다. `Enter` 또는 클릭으로 넘기고, `H`로 언제든 다시 봅니다. 전투 중 설명서를 열어도 전장 시계는 계속 흐릅니다.
- 챕터 선택: 위·아래 방향키나 목록 클릭으로 고르고 `Enter`로 출전합니다. `1~4`는 영구 강화 구매, `L`은 저장된 챕터 이어하기, `N`은 새 이야기 시작입니다.
- 결과: `Enter`로 챕터 선택, `R`로 재도전합니다. 승리 기준을 달성하면 다음 챕터가 열립니다. 챕터별 동시 전장 수는 `1, 1, 2, 2, 3, 3, 4, 4, 4, 4`개이며 전장마다 30분 시계가 있습니다.

## 전투 조작

왼쪽 전장에서 영웅은 자동으로 이동·공격하고 박쥐가 자동 투입됩니다. 전장 칸을 클릭하거나 `F1~F4`로 투입 대상을 고릅니다. 오른쪽의 몬스터 카드를 클릭하면 선택한 전장에 한 분대를 예약합니다. `Q/E`는 카드 페이지 전환입니다. 네 전장은 마력과 군단 경험치를 공유합니다. 모든 전장의 아군이 영웅에게 준 실제 피해가 공용 군단 경험치가 되고, **군단 레벨업마다 룰렛**이 열립니다. 상자 보상 수는 1개 72%, 3개 23%, 5개 5%입니다. 룰렛과 해금 중에도 전투는 계속됩니다.

중간보스와 30분 최종 결전에서 선택된 분신은 `WASD` 이동, 좌클릭 또는 `J` 공격, `K` 특수 공격, `Space` 회피로 조작합니다. 다른 전장의 분신은 자동으로 싸웁니다. 영웅은 보석·상자를 주워 무기와 아이템을 성장시키며, 각 전장 아래에 여섯 조합 상태가 표시됩니다.

다블라의 **영구 악마 레벨**은 전투 성과와 영구 강화 구매로 오르며 챕터 선택과 지휘실에 표시됩니다. **군단 레벨**은 챕터마다 1로 시작하고 이후 투입되는 몬스터에게 적용됩니다. 자세한 이야기와 규칙은 `CHAPTER_STORY_PROGRESSION_PLAN.md`를 참조하세요.

새 챕터 진행은 `user://save_chapter_v1.cfg`에, 영구 성장과 챕터 해금은 `user://save_observer_meta_v1.cfg`에 저장됩니다. 이전 다중 전장 `save_observer_multi_v1.cfg`, 단일 전장 `save_observer_v1.cfg`, 구 시제품 `save_v3.cfg`는 보존합니다. 기존 다중 전장 저장은 챕터 선택 화면에서 `L`로 불러올 수 있습니다.
